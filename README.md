# Thimbleweed Park 한글패치

**v0.1 alpha** — Thimbleweed Park을 한국어로 즐길 수 있게 해주는 팬 번역
패치입니다. 텍스트 번역은 100% 끝났지만 아직 정식 검수(QA) 전인 초기
버전입니다.

이 저장소에는 게임 리소스가 포함되어 있지 않습니다. 여기 담긴 건 번역된
텍스트/폰트/이미지 파일과, 그 파일들을 **정품으로 소유한 게임에 직접
적용해주는 설치 스크립트**뿐입니다. 자세한 설치 방법은
[installer/README.md](installer/README.md)를 확인하세요.

## 요약

- 설치 스크립트가 사용자의 `ThimbleweedPark.ggpack1`을 백업 → 로컬에서 압축
  해제 → 번역 파일로 덮어쓰기 → 재압축 → 교체합니다.
- 원본 게임 파일은 이 저장소 밖으로 전혀 나가지 않습니다.
- 게임 안에서 **옵션 > 언어(Language) 목록에서 "Korean Text"를 선택하면**
  한글로 표시됩니다 (원래 "German Text"였던 자리를 대체한 것으로, 내부적으로
  독일어 슬롯을 그대로 사용합니다).
- 완전히 제거하려면 `uninstall` 스크립트를 실행하면 원본으로 복원됩니다.

## 개발 히스토리

- 텍스트 12,900여 줄(대사, UI, 노트/일지 등 스탠드얼론 파일 포함) 전체 번역.
- 게임의 언어 슬롯 중 실제로 선택 가능한 "de"(독일어) 슬롯에 번역을 넣는
  방식을 채택. 이미지까지 전부 한글화하는 건 현실적으로 불가능해서, 이미지
  에셋의 "de" 참조는 전부 "en"(영어) 프레임을 가리키도록 리다이렉트해서
  그림은 원래 영어 그대로, 텍스트만 한글로 나오게 함.
- 엔진이 동사+목적어 문장을 항상 "동사 목적어" 순서(영어 어순)로 이어붙이는
  구조라 한국어 어순(목적어+동사)으로 자연스럽게 만들 수 없었음. 그래서
  `[줍기] 사과`, `[주기] 사과 > 윌`처럼 동사를 대괄호로 감싸고 "with/on/in/to"
  연결어를 `>`로 통일하는 표기법으로 절충.
- 비트맵 폰트 15종에 한글 글리프(KS X 1001 2,350자) 새로 추가. 처음엔
  글자별 베이스라인 계산이 틀려서 삐뚤빼뚤하게 나오는 문제가 있었는데,
  폰트의 공통 ascent 기준으로 다시 계산해서 해결.
- `Autosave`, 날짜/시간 포맷, `(casual)`/`(hard)` 같은 난이도 표기 등 일부
  시스템 문자열은 번역하면 엔진이 내부적으로 값을 못 찾아 빈칸으로
  나오는 걸 확인하고 원문 영어로 되돌림.
- `ThimbleweedText_*.tsv` 체계 밖에 있는 별도 텍스트 파일(노트, 수첩, 척의
  일지, 크레딧 등)이 뒤늦게 발견되어 추가로 번역.
- 실제 플레이하면서 발견된 버그들(Save/Load 라벨 뒤바뀜, 존댓말/반말 오류,
  "beep→삐-" 치환만 되고 나머지 문장은 번역이 안 남아있던 랜섬 대사 다수 등)을
  계속 찾아서 수정.
- 정품 게임 파일을 직접 배포하지 않기 위해, 원본과 비교해서 실제로 바뀐
  파일만 추려낸 "패치" 형태로 설치 스크립트를 구성 (Mac/Windows).
