Thimbleweed Park 한글패치v0.1 alpha

Thimbleweed Park을 한국어로 즐길 수 있게 해주는 팬 번역 패치입니다. 텍스트 번역은 100% 끝났지만 아직 정식 검수(QA) 전인 초기 버전입니다.

이 페이지는 게임을 배포하지 않습니다. 정품으로 게임을 이미 소유한 사람이 텍스트/폰트를 한글로 교체하는 패치 파일과 설치 스크립트만 제공합니다.

다운로드

저장소 전체를 받을 필요 없이, 설치에 필요한 파일만 압축된 릴리스를 받으면 됩니다 (Mac용 스크립트+도구, Windows용 스크립트+도구, 번역 패치 파일이 모두 들어있습니다).

⬇ 설치 파일 다운로드 (.zip) GitHub 저장소 (소스 보기)

스크린샷

설치 방법

자세한 설치 방법은 저장소의 installer/README.md를 참고하세요. 요약하면:

  1. 위에서 zip을 받아 압축을 푼다
  2. 게임 폴더에서 ThimbleweedPark.ggpack1 파일 위치를 찾는다
  3. Mac은 mac/install.sh, Windows는 windows/install.bat 실행 (Steam/GOG 기본 위치에 설치했다면 경로 입력 없이 Enter만 눌러도 자동으로 찾습니다)
  4. 게임 옵션의 언어(Language) 목록에서 "Korean Text"를 선택하면 한글로 표시됨 (원래 "German Text"였던 자리를 대체한 것으로, 내부적으로 독일어 슬롯을 그대로 사용합니다)

제거 방법

uninstall.sh / uninstall.bat 실행 시 원본으로 복원됩니다.
