Thimbleweed Park 한글패치v0.9 beta

Thimbleweed Park을 한국어로 즐길 수 있게 해주는 팬 번역 패치입니다. 텍스트 번역은 100% 끝났고, 캐릭터 간 대화 존댓말/반말 일관성 등 대사 검수도 상당 부분 마친 베타 버전입니다. 어색한 번역이나 버그를 발견하시면 Issues에 남겨주세요.

이 페이지는 게임을 배포하지 않습니다. 정품으로 게임을 이미 소유한 사람이 게임 폴더에 파일 하나만 복사해 넣으면 되는 번역 패키지를 제공합니다. 설치 스크립트나 별도 도구는 필요 없습니다.

다운로드

번역 파일만 담은 ThimbleweedPark.ggpack4 하나와 설치 안내문이 든 zip 파일입니다.

⬇ 패치 다운로드 (.zip) GitHub 저장소 (소스 보기)

한글화 범위

✅ 한글화된 것

  • 대사·자막 12,900여 줄 전체 번역
  • 게임 UI·폰트 동사, 인벤토리, 메뉴, 옵션 등 + 폰트 34종 전체
  • 스탠드얼론 텍스트 노트, 수첩, 척의 일지, 크레딧 등
  • 배경 이미지 진행에 중요한 화면들과 마을 곳곳의 간판 다수

⏳ 한글화 안 된 것

  • 배경 속 그림 텍스트 나머지 간판·낙서·전단지 등, 계속 진행 중
  • 조작법 안내 화면 HelpScreen 39장 (진행 필수 아닌 튜토리얼)
  • 일부 시스템 문자열 Save/Load 화면의 (casual)/(hard) 표기 등 — 게임 엔진 자체 버그로 한글 표시 불가

설치 방법

자세한 설명은 저장소의 README.md를 참고하세요. 요약하면:

  1. 위에서 zip을 받아 압축을 푼다
  2. 게임 폴더에서 ThimbleweedPark.ggpack1 파일 위치를 찾는다 (Mac은 게임 앱을 우클릭 → "패키지 내용 보기" → Contents/Resources/, Windows는 Steam 설치 폴더)
  3. 압축 푼 ThimbleweedPark.ggpack4 파일을 ThimbleweedPark.ggpack1이 있는 그 폴더에 그대로 복사
  4. 게임 옵션의 언어(Language) 목록에서 "Korean Text"를 선택하면 한글로 표시됨 (원래 "German Text"였던 자리를 대체한 것으로, 내부적으로 독일어 슬롯을 그대로 사용합니다)

게임 엔진이 원래 ggpack3, ggpack4처럼 번호가 이어지는 추가 패키지 파일을 자동으로 얹어서 읽습니다 (공식 "Ransome Uncensored" DLC도 ggpack3으로 같은 방식을 씁니다). 그래서 ggpack1/ggpack2는 전혀 건드리지 않고, 번역 파일이 담긴 패키지 하나를 그 옆에 놓기만 하면 됩니다.

제거 방법

게임 폴더에 복사해 넣은 ThimbleweedPark.ggpack4 파일을 삭제하면 원래 상태로 완전히 돌아갑니다.
