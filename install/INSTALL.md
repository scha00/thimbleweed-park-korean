# Thimbleweed Park 한글패치 설치 방법

## 설치

1. 게임 폴더에서 `ThimbleweedPark.ggpack1` 파일이 있는 위치를 찾습니다.
   - **Windows (Steam)**: 보통
     `C:\Program Files (x86)\Steam\steamapps\common\Thimbleweed Park\`
     폴더 안에 있습니다.
   - **Mac (Steam)**:
     `~/Library/Application Support/Steam/steamapps/common/Thimbleweed Park/Thimbleweed Park.app`
     이 앱을 Finder에서 우클릭 → "패키지 내용 보기" → `Contents/Resources/`
     안에 있습니다.
   - GOG 등 다른 버전도 폴더 구조는 비슷합니다. `ThimbleweedPark.ggpack1`
     파일을 직접 찾으면 됩니다.

2. 이 zip 안에 들어있는 `ThimbleweedPark.ggpack4` 파일을 위에서 찾은
   `ThimbleweedPark.ggpack1`이 있는 바로 그 폴더에 복사해 넣습니다.

3. 게임을 실행하고 옵션(Options) > 언어(Language) 목록에서
   **"Korean Text"**를 선택하면 한글로 표시됩니다.
   (원래 "German Text"였던 자리를 대체한 것으로, 내부적으로 독일어
   슬롯을 그대로 사용합니다.)

`ThimbleweedPark.ggpack1` / `ggpack2` 파일은 전혀 건드리지 않습니다.

## 제거

게임 폴더에 복사해 넣은 `ThimbleweedPark.ggpack4` 파일을 삭제하면
원래 상태로 완전히 돌아갑니다.
